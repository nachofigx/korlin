# 📚 Manual de Estudio — Korlin (Shortlang)

**Bienvenido a Korlin** /ˈkoɾlin/ — una lengua construida *"elegante y corta"*:
fácil de pronunciar, que condensa conceptos, hace la mentira costosa y detectable,
y está lista para la era digital y la IA.

Este manual te lleva de cero a hablar Korlin en 11 lecciones.

## Lección 1 — Pronunciación

Korlin se pronuncia **neutro**, como el español o el latín. 20 sonidos, 20 letras.
**Una letra = un sonido, siempre.** Sin excepciones.

### Vocales (5, puras)
| Letra | Suena como (español) |
|---|---|
| a | c**a**sa |
| e | m**e**sa |
| i | s**í** |
| o | n**o** |
| u | t**ú** |

### Consonantes (15)
| Letra | Suena como | | Letra | Suena como |
|---|---|---|---|---|
| p | **p**an | | s | **s**ol (nunca "z") |
| b | **b**ar | | h | **h**ouse (inglesa, sonora) |
| t | **t**an | | l | **l**uz |
| d | **d**ar | | r | pe**r**o (r suave) |
| k | **c**asa | | w | **w**ater (inglesa) |
| g | **g**ato | | y | **y**o |
| m | **m**ano | | f | **f**e |
| n | **n**o | | | |

### Reglas de oro
1. Vocales **puras**: nunca diptongues ("e" = [e], no [ei]).
2. **Sin soplo** en p, t, k.
3. **r suave** siempre [ɾ].
4. **s** siempre [s].
5. **h** siempre sonora [h].

### Práctica de sílabas
```
ka ke ki ko ku   pa pe pi po pu   ta te ti to tu
sa se si so su   ma me mi mo mu   na ne ni no nu
ra re ri ro ru   la le li lo lu
```

## Lección 2 — Saludos y presentarse

| Korlin | Español |
|---|---|
| **halo** | hola |
| **mi** | yo |
| **tu** | tú |
| **e** | ser/estar |
| **nom** | nombre |
| **de** | de |

**Ejemplos:**
- `Halo! Mi e-sa Ana.` — "¡Hola! Yo soy Ana."
- `Mi nom e-sa Korlin.` — "Mi nombre es Korlin."

> ⚠️ **¿Qué es `-sa`?** Lo verás en la Lección 6. Por ahora: toda afirmación en Korlin
> lleva una marca que indica *cómo sabes* lo que dices. `-sa` = "se sabe / es un hecho".

---

## Lección 3 — Ser/estar y las partículas

La cópula **`e`** sirve para "ser" y "estar" (no hay distinción).

| Partícula | Significado |
|---|---|
| e | ser / estar |
| a | a, hacia |
| i | en, dentro |
| o | o |
| u | un, una (y el número "uno") |

**Ejemplos:**
- `Mi e i le ho.` — "Estoy en la casa."
- `Le lin e ko.` — "La lengua es corta."

### Vocabulario nuevo
`ko` = corto · `lin` = lengua · `ho` = casa · `le` = el/la

## Lección 4 — Pronombres y determinantes

### Pronombres (sin género)
| Korlin | Español | | Korlin | Español |
|---|---|---|---|---|
| mi | yo | | wi | nosotros |
| tu | tú | | yu | vosotros/ustedes |
| li | él/ella | | lis | ellos/ellas |

### Determinantes
| Korlin | Español |
|---|---|
| le | el/la |
| se | este/a |
| te | ese/a |
| ke | aquel/la |

### Plural
El plural se forma con **`-s`**: `li` (él) → `lis` (ellos) · `ho` (casa) → `hos` (casas).

**Ejemplos:**
- `Lis e i le ho.` — "Ellos están en la casa."
- `Se ho e me.` — "Esta casa es grande." (`me` = grande)

## Lección 5 — Verbos y tiempos

Los verbos **no cambian por persona** (igual que en inglés, más simple que en español).

| Verbo | Significado | | Verbo | Significado |
|---|---|---|---|---|
| go | ir | | sa | saber |
| ve | ver | | pa | hablar |
| di | decir | | fa | hacer |
| man | comer | | bi | beber |
| do | dormir | | vi | vivir |
| ha | tener | | vo | querer |
| kan | poder | | da | dar |

### Tiempos (prefijos)
| Tiempo | Prefijo | Ejemplo |
|---|---|---|
| Presente | (nada) | `mi go` = "voy" |
| Pasado | **an-** | `mi an-go` = "fui" |
| Futuro | **ne-** | `mi ne-go` = "iré" |

> 💡 **Truco de memoria**: `an` = "viejo" (pasado) y `ne` = "nuevo" (futuro).

**Ejemplos:**
- `Mi man-ve le man-re.` — "Como la comida." (`man-re` = comida, Lección 8)
- `Wi an-go a le ho.` — "Fuimos a la casa."
- `Li ne-vi i Yapan.` — "Vivirá en Japón." (`Yapan` = Japón)

## Lección 6 — Evidencialidad (la firma de Korlin) ⭐

**Esta es la característica más importante y única de Korlin.**

En Korlin, **toda afirmación debe declarar su fuente**: no puedes decir "él se fue"
sin decir *cómo lo sabes*. Es obligatorio.

### Los 4 evidenciales (sufijos en el verbo)
| Sufijo | Fuente | Significado |
|---|---|---|
| **-ve** | directo | "lo vi / lo percibí con mis sentidos" |
| **-pen** | inferido | "lo deduzco de la evidencia" |
| **-di** | reportado | "me lo dijeron" |
| **-sa** | asumido | "se sabe / se asume" |

**Ejemplos (misma frase, 4 fuentes):**
- `li go-ve.` — "Él se fue (**lo vi**)."
- `li go-pen.` — "Él se fue (**lo infiero**)."
- `li go-di.` — "Él se fue (**me lo contaron**)."
- `li go-sa.` — "Él se fue (**se asume**)."

> 🧠 **Por qué existe esto**: hace la mentira *costosa y detectable*. Si dices `li go-ve`
> ("lo vi"), te comprometes a haberlo presenciado. Mentir exige un compromiso explícito.

## Lección 7 — Modalidad epistémica (grado de certeza)

Además de la *fuente* (Lección 6), puedes marcar tu *grado de certeza*. Son
**opcionales** (si no pones ninguna, se entiende "cierto").

| Partícula | Certeza | Equivalente |
|---|---|---|
| to | cierto | ✅ "en serio" |
| be | probable | 👍 "creo que sí" |
| os | posible | 🤔 "quizás" |
| ku | dudoso | ⚠️ "no me fío" |

**Ejemplos:**
- `li go-di be.` — "Se fue (me lo contaron), **probablemente**."
- `li go-pen os.` — "Se fue (lo infiero), **posiblemente**."
- `li go-di ku.` — "Se fue (me lo contaron), **dudoso, no me fío**."

## Lección 8 — Derivación (la fábrica de palabras) 🧩

No memorices miles de palabras: **derívalas** de raíces con afijos.

### Afijos derivacionales
| Afijo | Significado | Ejemplo |
|---|---|---|
| **-pe** | persona que X | `sa-pe` = sabio ("persona que sabe") |
| **-lo** | lugar donde se X | `man-lo` = comedor |
| **-re** | cosa de X | `man-re` = comida |
| **-i** | relativo a X | `su-i` = solar |
| **-ro** | cualidad de X | `gu-ro` = bondad |
| **na-** | opuesto | `na-gu` = malo |
| **me-** | grande/muy | `me-gu` = excelente |
| **pi-** | pequeño | `pi-ho` = casita |

**Ejemplos:**
- `sa` (saber) → `sa-pe` sabio · `sa-re` conocimiento · `na-sa` ignorar
- `do` (dormir) → `do-lo` dormitorio · `do-re` sueño
- `toro` (verdad) → `na-toro` mentira ("no-verdad")

## Lección 9 — Sintaxis (orden de palabras)

### Orden básico: Sujeto-Verbo-Objeto (SVO)
`Mi go a le ho.` — "Voy a la casa."

### El modificador va ANTES del sustantivo
`me ho` = "casa grande" (literal "grande casa")
`le gu pe` = "la buena persona"

### Negación: `na` antes del verbo
`Mi na sa.` — "No sé."

### Preguntas
- Sí/no: partícula **`mo`** al final → `Tu go mo?` = "¿Vas?"
- Interrogativas: al inicio → `ki pe e i le ho?` = "¿Quién está en la casa?"
  (`ki` = qué · `ki pe` = quién · `ki lo` = dónde · `ki tem` = cuándo)

### Posesión: `de`
`le ho de mi` = "mi casa" (literal "la casa de mí")

### Subordinación: `ki`
`Mi sa-ve ki li an-go-di.` — "Sé que él se fue (me lo contaron)."

## Lección 10 — Emociones (partículas de actitud) 😀

Como hablar con emojis. Se colocan **al final** de la oración.

| Partícula | Emoción | | Partícula | Emoción |
|---|---|---|---|---|
| yo ❤️ | alegría | | pu 🤢 | asco |
| hu 😢 | tristeza | | ni 😨 | miedo |
| we 😮 | sorpresa | | la 🥰 | cariño |
| fi 🙃 | ironía | | ri 😂 | risa |
| bu 😤 | enfado | | | |

**Ejemplos:**
- `Le jo e gu yo!` — "¡El día es bueno, me encanta!"
- `We! Le su e hi.` — "¡Wow! El sol está alto."
- `Mi go a le ho fi.` — "Voy a la casa (ironía)."

## Lección 11 — Números

`u`=1 · `du`=2 · `san`=3 · `fu`=4 · `sin`=5 · `sis`=6 · `sem`=7 · `om`=8 · `nu`=9 · `des`=10

**Componer** (regular):
- 11 = `des-u` · 20 = `du-des` · 25 = `du-des-sin` · 100 = `des-des`

## Textos de práctica

### Texto 1 — Presentación de Korlin
> **Halo! Mi e-sa Korlin. Mi e-sa u ko lin. Mi e-sa ra ka gu. Na-toro na-kan-sa vi i mi. Mi pa-ve kon pe ka kon kin. Tu kan-ve sa mi. Ven kon mi yo!**

Traducción: "¡Hola! Soy Korlin. Soy una lengua corta. Soy rápida y buena. La mentira
no puede vivir en mí. Hablo con personas y con máquinas. Puedes aprenderme. ¡Ven conmigo!"

### Texto 2 — Vida cotidiana
> `Mi an-go-ve a le ho, ka mi an-man-ve le man-re, ka so mi an-do-ve.`
"Fui a la casa, comí la comida, y luego dormí." (todo "lo viví/lo sé")

## Ejercicios

**1. Pronuncia** estas palabras en voz alta: `ko`, `lin`, `man`, `sape`, `natoro`.

**2. Traduce a Korlin:**
a) "Yo voy" → ______
b) "Él comió (lo vi)" → ______
c) "Tú dormirás" → ______
d) "La casa pequeña" → ______
e) "¿Vas?" → ______

**3. Traduce a español:**
a) `li go-di` → ______
b) `mi na sa` → ______
c) `sa-pe` → ______
d) `le gu pe` → ______

**4. Deriva** con afijos:
a) "dormitorio" (de `do` = dormir) → ______
b) "comida" (de `man` = comer) → ______
c) "malo" (de `gu` = bueno) → ______
d) "mentira" (de `toro` = verdad) → ______

### Respuestas
**2:** a) `mi go` · b) `li an-man-ve` · c) `tu ne-do` · d) `le pi ho` · e) `tu go mo?`
**3:** a) "él se fue (me lo contaron)" · b) "no sé" · c) "sabio" · d) "la buena persona"
**4:** a) `do-lo` · b) `man-re` · c) `na-gu` · d) `na-toro`
