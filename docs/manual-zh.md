# Korlin 手册（中文）

**Korlin**（/ˈkoɾlin/）是一种*简短、诚实、现代*的人造语言。

## 发音

**黄金法则**：元音纯正 · p/t/k 不送气 · r 为闪音 · s 始终 [s] · h 始终有声。

## 基本语法

- **语序**：主-谓-宾（SVO）。`mi go a le ho` =「我去房子」。
- **修饰语在核心词之前**：`me ho` =「大房子」。
- **复数**：后缀 `-s`。`li` → `lis`。
- **时态**：`an-`（过去）、`ne-`（将来）；现在时无标记。
- **示证（强制）**：`-ve`（直接）、`-pen`（推断）、`-di`（转述）、`-sa`（假定）。
- **认识情态**：`to`（确定）、`be`（可能）、`os`（也许）、`ku`（存疑）。
- **否定**：`na` 置于动词前。
- **是非疑问句**：`mo` 置于句末。
- **所有格**：`de`。**从句**：`ki`。
