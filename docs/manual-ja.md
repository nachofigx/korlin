# Korlin マニュアル（日本語）

**Korlin**（/ˈkoɾlin/）は*短く、誠実で、現代的*な人工言語です。

## 基本文法

- **語順**：主語-動詞-目的語（SVO）。`mi go a le ho` =「私は家に行く」。
- **修飾語は主要部の前**：`me ho` =「大きな家」。
- **複数**：接尾辞 `-s`。`li` → `lis`。
- **時制**：`an-`（過去）、`ne-`（未来）；現在は無標。
- **証拠性（必須）**：`-ve`（直接）、`-pen`（推論）、`-di`（伝聞）、`-sa`（想定）。
- **認識モダリティ**：`to`（確実）、`be`（多分）、`os`（可能）、`ku`（疑わしい）。
- **否定**：`na` を動詞の前に。
- **Yes/No 疑問**：`mo` を文末に。
- **所有**：`de`。**従属節**：`ki`。
